Ribble for OS/2 - Version 1.1
===============================


OVERVIEW
--------
Ribble is a Boulder Dash style puzzle game for OS/2 and ArcaOS, ported
and updated to a 32-bit Presentation Manager application built with
Open Watcom.

Guide the cute green tribble through a series of caves, collecting
diamonds while avoiding rocks and monsters. Reach the exit of each
level to advance.

In keeping with the original 1993/1994 release, Ribble keeps the
classic game play: dig through earth, push and avoid boulders, hatch
eggs, dodge monsters and teleport around the caves.


HOW TO PLAY
-----------
- Arrow keys move the little man; use the keyboard mapping from
  Options > Settings... to pick your preferred control scheme.
- Collect all the diamonds to open the exit (cage drops).
- Avoid rolling boulders, bombs and monsters.
- Space bar toggles the map panel on/off.
- Start a new game from Game > New Game (Ctrl+N).
- Quit the current game (showing scores) via Game > End Game (Ctrl+Q).
- Exit the application via Game > Exit (Ctrl+X).


CONTROLS
--------
  Arrow keys        Move
  Space bar         Toggle map
  Ctrl+M            Toggle map panel
  Ctrl+T            Show status bar
  Ctrl+N            Start a new game
  Ctrl+O            Open a saved level
  Ctrl+S            Save the current level
  Ctrl+Q            Quit current game (shows scores)
  Ctrl+X            Exit application

  Custom key bindings can be set under Options > Settings...


MENUS
-----
  Game > New Game          Start a new game (Ctrl+N)
  Game > End Game          End current game (shows scores) (Ctrl+Q)
  Game > Open...           Open a saved level (Ctrl+O)
  Game > Save...           Save the current level (Ctrl+S)
  Game > Map...            Toggle the map panel (Ctrl+M)
  Game > Status...         Show status bar (Ctrl+T)
  Game > Exit              Close the application (Ctrl+X)

  Options > Map Editor > Level...    Level editor
  Options > Map Editor > Options...  Editor options

  Options > Settings...    Game and control settings
  Options > Language       Switch display language (English, Spanish,
                           Dutch, German, French, Italian; also
                           switches the online help language)
  Options > Save settings on exit

  Help > Help for help...  Help on using help (Shift+F10)
  Help > Extended help...  Extended help on the current topic (F2)
  Help > Keys help...      Keyboard help (F9)
  Help > Help index...     Open the help index (F11)
  Help > About...          About Ribble
